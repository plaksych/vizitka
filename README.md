# Описание проекта

Этот проект — простой сайт-визитка. Подходит для представления компании, услуги или личного портфолио. Сайт содержит основную информацию: контакты, описание деятельности, возможно галерею работ и форму обратной связи.
## Технологии:

* HTML5
* CSS3
* JavaScript

## Как запустить

* Скачайте все файлы проекта в одну папку.
* Откройте файл index.html в любом современном браузере.

Или используйте локальный сервер (например, с помощью VS Code Live Server).
